# ภาพรวมโครงการ

## เป้าหมาย

โครงการนี้สร้างเกมจำลองอาณานิคมอวกาศที่ colonist แต่ละคนเป็น AI agent อิสระซึ่งรับรู้สถานะโลก ประเมินสภาวะภายใน และตัดสินใจเอง ผู้เล่นทำหน้าที่เป็นผู้ออกแบบอาณานิคมและผู้จัดการวิกฤต โดยกำหนดสภาพแวดล้อมและนโยบายแทนการออกคำสั่งตรงแก่ colonist

## เสาหลักหกข้อ

1. People Over Resources — ปัญหาทรัพยากรมักมีมิติของผู้คนอยู่เบื้องหลัง
2. Conditions, Not Commands — ผู้เล่นสร้างเงื่อนไขแทนการสั่ง colonist โดยตรง
3. Every Story Is True — พฤติกรรมที่มองเห็นต้องมีสาเหตุจริงและตรวจสอบย้อนกลับได้
4. Legible Complexity — ระบบอาจซับซ้อนได้ แต่ผู้เล่นต้องอ่านและเข้าใจเหตุผลได้
5. The Colony Has a Culture — รูปแบบร่วมของอาณานิคมเกิดจากประวัติและความสัมพันธ์
6. Failure Is Information — ความล้มเหลวต้องให้ข้อมูลที่ช่วยอธิบายสาเหตุ

## กลุ่มผู้เล่น

- ผู้เล่นเกมวางแผนและบริหารที่ต้องการระบบลึกและเรื่องราวที่เกิดจากการจำลอง
- ผู้เล่นที่สนใจระบบเกิดใหม่และการตัดสินใจของ AI ที่อธิบายได้
- โครงการไม่ได้มุ่งที่การต่อสู้รวดเร็ว การเพิ่มอำนาจแบบฉับไว หรือเรื่องเล่าที่กำหนดไว้ตายตัว

## หมุดหมายตามวิสัยทัศน์

- Alpha — สถานีหนึ่งแห่ง colonist ประมาณ 20 คน วงจรความต้องการหลัก และการตัดสินใจที่ผู้เล่นตรวจสอบได้
- Beta — ความสัมพันธ์ กลุ่มย่อย วิกฤต และ AI Director
- 1.0 — หลายสถานี การเมืองระหว่างอาณานิคม save/load และการรองรับส่วนเสริม

## โครงสร้าง repository โดยย่อ

| ไดเรกทอรี | หน้าที่ |
|---|---|
| `prototype/` | โค้ด TypeScript ที่รันได้จริงสำหรับการจำลองแบบ headless และชุดทดสอบ |
| `ai-studio/` | กฎพื้นฐาน governance workflow บทบาท และ ADR |
| `design/` | ข้อกำหนดการออกแบบเกมและระบบ |
| `docs/` | เอกสารโครงการ คู่มือ และ workflow pack |
| `game/` | แหล่งอ้างอิงเชิงสร้างสรรค์ของเกม |
